# DisplayToggle 安装说明

开盖状态下彻底关掉 MacBook 内置屏的菜单栏小工具。

## 系统要求

- **macOS 13.0（Ventura）或更高**
- 支持 **Apple Silicon（M 系列）和 Intel** —— 通用二进制，两个架构都在同一个包里
- 需要是笔记本（有内置屏）；台式机上程序会提示找不到内置屏

## 安装

### 方式一：.pkg 安装包

双击 `DisplayToggle-1.0.0.pkg`，一路点下去即可。程序会被装到 `/Applications`。

### 方式二：.dmg 磁盘镜像

双击 `DisplayToggle-1.0.0.dmg`，把 `DisplayToggle` 拖到旁边 `Applications` 文件夹里。

---

## ⚠️ 首次打开会被系统拦截（这一步必看）

程序**没有用 Apple 开发者证书签名**（那个需要每年 $99 的开发者账号），
所以 macOS 会提示「无法打开"DisplayToggle"，因为它来自身份不明的开发者」。

### 解决办法

1. **右键**（或按住 Control 点按）`DisplayToggle` 图标
2. 选择 **「打开」**
3. 在弹出的确认框里再点 **「打开」**

只需这样操作一次，以后就能正常双击启动了。

> 如果右键菜单里也没有「打开」选项：
> 系统设置 → 隐私与安全性 → 向下滚动到「安全性」区域，
> 会看到「DisplayToggle 已被阻止使用，因为它来自身份不明的开发者」，
> 点 **「仍要打开」** 即可。

---

## 使用

启动后菜单栏会出现一个显示器图标（不会有 Dock 图标，这是正常的）。

| 操作 | 效果 |
|---|---|
| **⌃⌥⌘D** | 开关内置屏 |
| 点菜单栏图标 → 关闭/恢复内置屏 | 同上 |
| 点列表里任意一块屏 | 单独开关那一块 |
| 「关于」 | 查看后端状态、快捷键模式 |

菜单里最后一块还在输出的屏会**变灰并标注「最后一块屏，禁止关闭」**，
防止误操作把两块屏全关掉。

命令行用法见 README.md。

---

## 卸载

1. 删掉 `/Applications/DisplayToggle.app`
2. 如果勾过「开机时启动」，先到 系统设置 → 通用 → 登录项与扩展 里移除
3. 想连配置一起清掉（可选）：
   ```bash
   defaults delete com.local.displaytoggle
   ```

## 分发前自己签名（可选）

如果你有 Apple 开发者账号，重签一下就能省掉上面「右键打开」的麻烦：

```bash
# 1. 查看证书名称
security find-identity -v -p codesigning

# 2. 重签名
codesign --force --deep --options runtime \
  --sign "Developer ID Application: 你的名字 (TEAMID)" \
  /Applications/DisplayToggle.app

# 3. 验证（应输出 accepted）
spctl -a -vv /Applications/DisplayToggle.app
```

重签后再跑 `./package.sh` 重新打包即可。
`package.sh` 会**自动检测**机器上有没有可用证书，有的话就直接用它签名。

## 已知限制

- **「接上外接屏自动开关内屏」尚未在多种机型上验证过。**
  它依赖真实的硬件热插拔事件。你插拔一次显示器线就知道生效没有；
  如果没反应，改手动开关即可。
- 程序使用了系统私有 API（`CGSConfigureDisplayEnabled`），
  未来 macOS 大版本升级有失效的可能。届时程序会提示「本机未找到符号」，
  可以改用 BetterDisplay / Lunar 后端（菜单 → 后端 里切换）。
