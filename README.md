# Michael-macOS-APP

控制多显示器开启和关闭的 macOS 工具 / A macOS tool to control multiple displays on/off

## 功能介绍 / Features

- 快速开启和关闭外接显示器
- 支持多显示器管理
- 一键切换显示模式

## 系统要求 / Requirements

- macOS 系统
- 支持多显示器配置

## 安装方法 / Installation

1. 下载 `DisplayToggle-1.0.0.pkg`
2. 双击运行安装包
3. 按照提示完成安装

## 使用方法 / Usage

安装完成后，在应用程序中找到 DisplayToggle 并运行。

## 版本信息 / Version

- 当前版本：1.0.0
- 文件大小：约 120KB
